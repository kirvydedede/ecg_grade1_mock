心電図検定1級 模擬試験 PWA

■ 使い方
1. このフォルダをWebサーバー上に置いて index.html を開きます。
2. iPhone: Safariの共有 →「ホーム画面に追加」
3. Android: Chromeメニュー →「ホーム画面に追加」または「アプリをインストール」

■ ローカル確認
PCでこのフォルダを開き、ターミナルで以下を実行:
  python3 -m http.server 8000
ブラウザで http://localhost:8000 を開く。

■ 機能
- 本番模試: 50問 / 90分
- 10問練習
- 苦手問題の復習
- 問題フラグ
- 解説表示
- localStorageによる成績・苦手問題保存
- オフライン対応(PWA)

■ 注意
問題は学習用に独自作成したものです。日本不整脈心電学会の公式問題の転載ではありません。
一部の心電図は判読練習用の模式図で、臨床診断用の実波形ではありません。
